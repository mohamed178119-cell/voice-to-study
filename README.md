# Study Buddy AI

اريد تطبيق ذكاء  اصطناعي مساعد دراسي لا يرد الا علي الرسائل الدراسيه باستخدام الضابط المدرسي وكمان يقدر يحللpdfللمنهج او الدراسه ويجيب عن أي اسئله وكمان يقدر تفعله صوره تحلها ويحل الاسئله الدراسيه  وكمان يقدر ياخد فويس دراسى يلخصه او تسجل مباشر  وكمان يقدر يبعتلك pdf او صور لحجات في المنهج 

التطبيق عباره عن eواجهات اول واجهة رفع الصور وpdf تاني واجهة رفع التسجيل او التسجيل مباشر تالت واجهة مميزات التطبيق مع المصمم محمد سعد
